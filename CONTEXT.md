# Routing

| If the user wants to… | Read |
|---|---|
| Set up the workspace (first time) | `setup/questionnaire.md` |
| Start a new run / identify the ROM | `stages/01_recon/CONTEXT.md` |
| Build the character table and dump text | `stages/02_extract/CONTEXT.md` |
| Translate text | `stages/03_translate/CONTEXT.md` |
| Redraw text that is part of the graphics (titles, labels, buttons) | `stages/03b_graphics/CONTEXT.md` |
| Make the patched ROM and patch file | `stages/04_build/CONTEXT.md` |
| Log or fix bugs after play-testing | `stages/05_playtest/CONTEXT.md` |
| Continue a run | `PROGRESS.md`, then the stage it names |

## Shared files
- `_config/rom-facts.md` — what we know about the ROM (filled by stages 01–02).
- `_config/glossary.md` — fixed English names and terms.
- `_config/style-guide.md` — tone and naming rules.
- `_config/legal.md` — patch-only sharing rules.
- `_config/tools.md` — Python, emulator, and script usage.
